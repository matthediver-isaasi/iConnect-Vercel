---
name: Public group reading policy
description: Publication consent and the approved read-only scope of public groups.
---
Public group consent includes linked resources and forum discussions, not merely
a summary preview. It must never create membership or confer participation,
administration, booking, application, email, project or repository privileges.
Joining and directory hiding remain independent.

**Why:** The owner explicitly replaced a guest-preview-only proposal with full
read-only content access while retaining independent privacy and access rules.

**How to apply:** Require explicit group publication and tenant/content lineage
for every guest read and file authorization. Group-membership restrictions alone
may be waived; independent resource release/category/attendance restrictions,
the resource's own Public Resource flag, member directory opt-outs, forum role
restrictions and moderation still apply. File publication must not bypass
independently protected gallery or opportunity document policies. Do not reinterpret
this consent as changing the legacy Canvas role-holder publication policy.
