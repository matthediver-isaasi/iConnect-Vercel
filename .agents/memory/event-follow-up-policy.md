name: Event follow-up policy
description: Owner-approved programme-wide end anchors and audience boundaries.

After-day timing is based on the programme's final session that day, not the
recipient's last accessible session. A separate after-event option must wait for
ALL days and sessions to finish and be available for every event type.

**Why:** The owner explicitly confirmed both requirements; a partial-programme
ticket changes relevant days/sessions, not the programme's overall completion.

**How to apply:** Keep day attribution on event-local start day for overnight
sessions. Do not infer daily timetables from continuous training ranges. Audience
remains eligible attendee bookings, never inferred attendance or all contacts.
Live sends, production requeues/backfills, tenant changes and production
deployment require separate approval.
