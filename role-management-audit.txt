ISSUE #1: INCONSISTENT FEATURE ID PREFIXES
================================================================================

Current prefix patterns in use:
- page_user_*     (e.g., page_user_BuyProgramTickets)
- page_admin_*    (e.g., page_admin_NewsSection)
- page_*          (e.g., page_Dashboard, page_EventDetails)
- element_*       (e.g., element_EventDescription)
- payment_*       (e.g., payment_training_vouchers)
- action_*        (e.g., action_news_edit)
- admin_*         (e.g., admin_can_edit_members)
- feature_*       (e.g., feature_PostJobOnBehalfOfOrg)
- edit_*          (e.g., edit_professional_biography)
- view_*          (e.g., view_member_biography)

PROBLEM: The Layout.jsx navigation uses DIFFERENT prefixes than what's 
defined in AVAILABLE_FEATURES:

Layout.jsx uses:          AVAILABLE_FEATURES defines:
-----------------         --------------------------
page_BuyProgramTickets    page_user_BuyProgramTickets
page_Events               page_user_Events
page_Bookings             page_user_Bookings
page_MyTickets            page_user_MyTickets
page_Balances             page_user_Balances
page_History              page_user_History
page_Team                 page_user_Team
page_MemberDirectory      page_user_MemberDirectory
page_OrganisationDirectory page_user_OrganisationDirectory
page_Resources            page_user_Resources
page_ArticlesSection      page_user_ArticlesSection
page_MyArticles           page_user_MyArticles
page_Articles             page_user_Articles
page_MyJobPostings        page_user_MyJobPostings
page_Preferences          page_user_Preferences
page_Support              page_user_Support
page_MyOrganisation       page_user_MyOrganisation

This means the feature exclusion checks MAY NOT WORK correctly because the 
IDs don't match!

================================================================================
RECOMMENDATIONS FOR CLEANUP
================================================================================

1. STANDARDIZE PREFIXES
   - Use consistent prefix pattern: {scope}_{category}_{pageName}
   - Examples:
     - user_page_Events
     - admin_page_RoleManagement
     - element_NewsTickerBar
     - action_NewsEdit
     - payment_TrainingVoucher
     - capability_EditMembers

2. ALIGN IDS BETWEEN SYSTEMS
   - Make Layout.jsx featureIds match AVAILABLE_FEATURES exactly
   - Or update AVAILABLE_FEATURES to match what Layout.jsx uses

3. ADD MISSING FEATURES
   - Add all 23 missing page/action features to AVAILABLE_FEATURES

4. GROUP BY FUNCTIONAL DOMAIN
   Instead of User/Admin split, consider:
   - Events & Bookings (user + admin pages together)
   - Members & Organizations
   - Content (Articles, News, Resources)
   - Job Board
   - Page Builder & Design
   - Forms
   - System Configuration

5. SEPARATE CONCERNS
   - Page Access: Controls visibility in navigation + page access
   - Element Visibility: Controls UI elements within pages
   - Actions: Controls specific actions (edit, delete, etc.)
   - Capabilities: Cross-cutting abilities (manage communications, etc.)
   - Payment Features: Payment method visibility
