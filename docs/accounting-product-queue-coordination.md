Product integration coordination:

- Commercial sales submit NEW requests when BOTH ACCOUNTING_REQUEST_QUEUE_ENABLED=true and ACCOUNTING_REQUEST_QUEUE_SOURCES includes sales_commercial_sale. Product source allowlist is deliberately limited to sales_commercial_sale. OFF retains the legacy writer only for fresh sources without an existing queue owner.
- Resume runs before current provider/customer/quote/tax preparation. Accepted pending requests throw ACCOUNTING_REQUEST_PENDING (409) with requestId and state, preserving the original attempt rather than marking it failed. Subsequent retry resumes the same sale.
- Pure prepareSalesAccountingEnvelope({provider,payload,environment}) uses existing Xero/QBO builders, preserves accepted economics and original claim operation key, and freezes readback expectations.
- Product link adapter exports linkAccountingProductSource({db,row}) for sales_commercial_sale and training_fund_purchase. Sales linkage is {saleId,quoteVersionId,attemptId,actorId}; training-fund linkage is {purchaseId,organizationId}. It never charges cards or increments balances.
- Training-fund producers are NOT opted in: creation/pending-balance/Stripe checkout continuation has no durable resumable state machine; card accounting payment has no prepared queue stage for existing invoices. The legacy paths remain operational even when sales adoption is enabled. Source rows are preserved on invoice uncertainty.
- Legacy generic Xero endpoint now requires authenticated tenant admin authority and uses only the authenticated tenant. It remains on its legacy writer: there is no server-owned durable source ID for safe queue adoption.
- Do not describe this as all-product central queue adoption. Existing sale queue ownership is always checked, including after flags are switched OFF. Only a missing queue table is tolerated in OFF mode; permissions/timeouts/other lookup failures fail closed. An accepted owner resumes without legacy fallback.
- Provider adapter now supports unitdp=4. Its normalized result still lacks status/URL/creation date; sales linkage retains unknown status until refresh, rather than inventing provider values.
