The scope below replaces the earlier proprietary mini-Canvas/scene-graph approach. It retains the useful work already completed—reference capture, Design DNA, versioning, prompt-led editing and Canvas integration—but changes the generated output to native, sanitised HTML/CSS/SVG rendered by the browser.

iConnect AI Design Studio V2
AI Code Composition and Visual Iteration
1. Project decision

The current AI Composition architecture should be revised.

The existing implementation asks AI to generate a proprietary layout document containing element hierarchy, coordinates, dimensions and styles, which is then translated by an iConnect renderer into HTML and CSS.

Testing has demonstrated that this approach:

Restricts the AI’s design capability.
Requires iConnect to reproduce browser-layout behaviour.
Creates fragile parent-child and geometry handling.
Produces invalid or incomplete CSS.
Makes responsive design substantially harder.
Introduces several transformation stages where valid layout information can be lost.
Does not reliably reproduce the quality that ChatGPT can achieve when generating native frontend code.

The replacement architecture should allow AI to generate:

Semantic HTML
Scoped CSS
Sanitised inline SVG
Media-library asset requests
Approved iConnect component slots
Responsive desktop, tablet and mobile behaviour

The browser should perform the layout using native HTML, CSS Grid, Flexbox and responsive media queries.

The product principle remains:

Customers direct the design through prompts; AI performs the design and implementation work.

7. Scoped CSS

Generated CSS must be isolated to the AI Composition instance.

The stored CSS should be parsed using a real CSS AST parser and rewritten under a unique wrapper:

<div data-ai-composition="composition-uuid">
    ...
</div>

Example:

[data-ai-composition="composition-uuid"] .hero {
  display: grid;
}

The scoping process must:

Prefix all selectors.
Reject global selectors.
Handle media queries.
Handle pseudo-elements.
Handle keyframes if limited animation is introduced later.
Prevent selectors from escaping the wrapper.
Prevent generated CSS from affecting sibling Canvas blocks.
Prevent generated CSS from affecting the Canvas editor.

Do not rely on string replacement alone.

Use a CSS parser and AST transformation.
